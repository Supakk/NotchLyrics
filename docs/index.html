Install in a minute.

Notchu is free. It is not notarized by Apple yet, so macOS asks you to confirm the first time you open it.

Download Notchu.dmg

Use the Download for Mac button. Every release is also listed on GitHub.

Drag Notchu into Applications

Open the disk image and drag the app onto the Applications shortcut.

Open it the first time

Open Notchu from Applications. If macOS says it cannot verify the developer, go to System Settings → Privacy & Security and click Open Anyway.

Allow access to your music app

Click OK when macOS asks to let Notchu control Music or Spotify. That is how it reads the current song and runs the controls.

Questions

Is Notchu really free?

Yes. No trial, no subscription, no paid tier. The source code is on GitHub.

Which Macs does it work on?

Any Mac on macOS 14 Sonoma or later. It is designed around the notch on recent MacBooks; on other screens it sits at the top centre instead.

Which music apps are supported?

Apple Music and Spotify. Synced lyrics come from Apple Music's own lyrics when available, otherwise from the free LRCLIB database.

Why does macOS warn me when I open it?

Apps that are not notarized by Apple show this warning the first time. Use Open Anyway in Privacy & Security once and it opens normally after that.

How do I remove it?

Quit Notchu from its menu bar icon and move it from Applications to the Trash.
